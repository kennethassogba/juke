# Harness Tycoon

You are the harness. A user sends a request; you assign an agent, give it a tool and environment, and send the reply. Requests and tool results are simulated inside the browser.

## First request

Learn by doing. The first request has no deadline. Choose Luna or Opus, wait for it to think, select Sandbox and Terminal, then send the reply. No other requests arrive during this introduction.

## Manage the queue

Each live request holds 1 to 3 context blocks once assigned. Context stays reserved until the reply is sent or the request expires. Your setup starts with 6 blocks and two agents. An agent is free once its thinking finishes; tool work uses a separate slot. You start with one tool slot.

- Code: Terminal in Sandbox.
- Research: Browser on the Web.
- Writing: Files in Workspace.

A wrong tool or environment does not spend resources. The game explains what to change. When context is full, finish an existing request before assigning another. When a tool is busy, an agent can think on another request.

Requests arrive in short waves. Prioritize deadlines. Three expired requests end the shift. A successful reply pays game credits and earns points; consecutive replies increase the score bonus. These credits have no monetary value.

Pause freezes arrivals, deadlines and progress. You can still arrange work while paused. Switching away from the tab pauses automatically. The 2× control advances every game clock together.

## Build your harness

Between waves, spend credits on another agent, larger context, parallel tools, faster workers or Auto-router. Each upgrade changes a working resource in the simulation. Another agent adds Terra, then Sol, up to four agents. Context, tool and speed upgrades each have three levels.

Auto-router chooses the earliest deadline, assigns a free agent, runs the correct tool when a slot opens, and sends finished replies. You can turn it off. Clearing wave 2 unlocks it for future shifts on this device, even without buying it. Only your highest cleared wave is saved; requests and running sessions are not stored. Clearing site storage resets that unlock.

Continue to the next wave or end your shift to see the score. New shift begins again with the first request and carries the wave-2 Auto-router unlock. Sharing copies or shares a score and game link; it does not post on your behalf.

## Game values

The agents use the cards’ reference model names, artwork and Intelligence Index. Thinking speed, specialist bonuses, context blocks, tool duration, deadlines, credits and upgrades are fictional game values. They are not measurements of a model or harness. No real code, browser sessions, tool calls or model API requests are executed.
