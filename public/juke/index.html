How to play

Touch the rink to start. Move the white paddle with your mouse, finger or arrow keys. Hit the puck into any coloured goal and protect your own.

You play against all three opponents at once. First to 5 wins. After 40 seconds, the higher score wins.

Each opponent chooses its next move through a real API call. Its response time and cost appear beside its name.

Decision models

JUKE explores how API response time changes a game. Three models see the same kind of physical state and choose from five moves.

GPT-6 Luna
Decisions API · choice question. Returns one allowed move directly.
GPT-5.6 Luna
Responses API · structured JSON · reasoning set to none.
GPT-4.1 nano
Responses API · structured JSON.

The puck keeps moving while they decide. Their moves take effect when the response arrives. Costs use actual token usage.

The idea comes from decision models such as Jev by TypeSafe. This arena runs the three OpenAI models listed above.
