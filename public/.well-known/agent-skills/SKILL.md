# Play catalogue

Read games with GET /api/games?q={query} or GET /api/games/{slug}. Read controls and model configurations before describing a game.

MCP endpoint: https://play.keff.uk/mcp. Tools: search_games, get_game. Browser WebMCP exposes the same tools. Search updates the visible results.

The tools are read-only and do not start matches, spend credits or change subscriptions. Never claim that Token Factory or Harness Tycoon makes live model calls. JUKE OpenAI mode uses real API calls and its displayed browser allowance.
