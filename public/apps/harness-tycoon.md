# Harness Tycoon

Assign agents to incoming requests, pick the right tools and send replies before the deadline. Build a faster setup between waves.

Play: https://play.keff.uk/harness-tycoon/
Install: https://play.keff.uk/harness-tycoon/?install=1
Manifest: https://play.keff.uk/harness-tycoon/manifest.webmanifest

## Controls

Choose a request, assign an agent, run its tool and send the reply. Pause to plan. Requests are simulated.

## Modes and rules

- Route requests through Browser, Terminal and Files.
- Buy more agents, context and parallel tools between waves.
- Unlock Auto-router and keep your best wave on this device.
